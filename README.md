# Advisor Platform

Multi-tenant, white-label SaaS for LinkedIn advisory professionals. See **[replit.md](./replit.md)** for the architecture, environment variables, boot seed and deploy steps, and `design_handoff/` for the design bundle this implementation follows.

```bash
pnpm install
pnpm dev        # http://localhost:5000
pnpm typecheck && pnpm test
```
